# 个人运行时的连续性与等待边界

个人版迁移以旧版已存在的角色和互动语义为依据，不因 Qt/Core 架构差异默认删除能力。
角色卡、系统约束、关系指引和 lore 各保留原加载职责；本契约不修改真实角色文本或关系参数。

## 对话间隔

普通用户轮在写入本轮输入前，从当前角色的既有 Timeline 上下文候选计算上次有效真人交流时间。
只计合法真人对话轮的 `human/chat` 及同轮 `assistant/chat`，排除观察、系统事件、独立主动发言、
坏时间和未来时间。复用已有读取，不新建第二份时间状态，也不依赖关系驱动开关。
运行时事实包含本地时段；间隔达到 120 秒后使用旧版时长格式器注入客观间隔，并明确不要将临时时刻写入长期记忆。
重开程序后继续从 Timeline 恢复。此间隔不是关系欲望值；关系驱动仍按原持久时间状态独立演化。

## 独白与亲密节奏

普通真人轮先启动既有独白 worker，再执行记忆上下文收集；首次主请求在收集后有界 join。
独白、interest、appraisal 和关系 fragment 在 join 后取值。最终 fragment 次序仍为 builtin、session、provider，
保留取消、角色、turn 与 epoch 隔离，不新建并行 worker 或跨轮缓存。

亲密模式沿用旧版节奏：仍用主对话模型，强制关闭 thinking；独白按 fast-tier 规则处理，
默认 `skip_fast_tier` 时不生成。用户显式关闭该跳过设置时仍遵循其配置。
不由关系数值自动开启亲密模式，不修改导演层的进入、退出及续投规则。

## 避免无效召回

回复格式/译文修复仅转换已有回复，不再调用上下文 providers 获取新事实，仍保留逐段译文完整性检查。
个人 Observer 的视觉、决策请求已经明确构造输入；Trace 元数据不得为了记录请求而再次收集 providers。
正常聊天的长期记忆召回保持有效，不以禁用记忆或加长插件期限掩盖迟返。
记忆完成日志仅增加 query-plan、search、selection 耗时，不记录查询或记忆正文。
